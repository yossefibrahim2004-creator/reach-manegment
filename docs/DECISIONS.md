## Audit pass — responsive + WCAG (2026-10-03)
- D-040 — **Every CSS grid must declare a base `grid-cols-1`** even when columns only appear at `sm:`/`lg:`. Without it the implicit track is `auto` and sizes to max-content, so a `truncate` (nowrap) string blows past the container: the home categories grid measured 352px in a 288px box → **49px horizontal scroll at 320px** (AR) / 3px (EN). `grid-cols-1` = `minmax(0,1fr)`, which both clamps the track and clamps the item's automatic minimum (verified: scrollWidth 369 → 320). Applied to 18 grids; intentional base-2/4 grids (admin stats, image thumbnails, hero cells) were left alone. (confirmed — measured)
- D-041 — Focus indicator is the global `:focus-visible { outline: 2px solid var(--color-fire-600); outline-offset: 2px }` (5.05:1 on light, 3.7:1 on navy, ≥3:1 per WCAG 1.4.11). It replaces the old 35%-alpha box-shadow ring (**1.78:1 — failed**) and its `border-radius` override (which squared off every rounded/pill control on focus). Components keep their own `focus-visible:outline-white` on dark bars. (confirmed — computed style: `2px solid rgb(215,38,30)`)
- D-042 — One dependency-free helper, `src/lib/use-dialog.ts` (`useDialogBehavior`), gives the filter drawer and the lightbox focus-in on open, a Tab trap, body scroll lock and focus restore on close (WCAG 2.4.3 / 2.1.2). No focus-trap library was added (D-014 free-tier rule). (confirmed — CDP interaction tests)
- D-043 — Touch targets: **44×44 for controls** (buttons, icon buttons, nav/chip/remove/close, socials), **≥24×24 for inline text links** (topbar, footer, e-mail/map/view-all) — SC 2.5.8 is AA at 24×24; a blanket 44×44 is AAA (SC 2.5.5) and would bloat the dense topbar/footer. Flagged as a deliberate deviation from the checklist's "44×44 on mobile". Filter checkboxes are 16×16 but wrapped in a 32×246 label row, which is the real target. (assumed — flag if you want strict 44 everywhere)
- D-044 — All text inputs/selects are `text-base` (16px) to stop iOS zoom-on-focus; admin fields also lost `outline-none`, which had been suppressing the global focus ring. (confirmed)
- D-045 — The mobile menu is absolutely positioned under the sticky header (`top-full`) instead of in flow: it previously pushed the page down **116px → 350px** on open. It closes on Escape (existing), on link click (existing) and now on an outside `pointerdown`. (confirmed — mainTop 121 → 121)
